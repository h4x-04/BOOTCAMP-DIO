# ☕ Java — Atividades DIO

Repositório criado para registrar minha jornada de aprendizado em **Java** durante o bootcamp da **DIO**.

Aqui estão reunidos exercícios, desafios e atividades desenvolvidos ao longo do curso, colocando em prática os conceitos estudados e acompanhando minha evolução na linguagem.

---

## 📚 Conteúdos estudados

Durante as atividades, foram praticados conceitos como:

* ☕ Fundamentos do Java
* 📦 Variáveis e tipos de dados
* ⌨️ Entrada e saída de dados
* ➕ Operadores
* 🔀 Estruturas condicionais
* 🔁 Estruturas de repetição
* 🎯 `switch/case`
* 🧩 Métodos
* 📋 Arrays
* 🧠 Lógica de programação
* 🏗️ Programação Orientada a Objetos
